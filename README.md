# YMMResourcePackager

YMM4 向けのリソースパッカー / アンパッカーです。`.ymmp` プロジェクトを `.ymmpx` にまとめたり、`.ymmpx` を展開して再び編集可能な状態へ戻したりできます。

## 主な機能

- `.ymmpx` YMMP同梱ファイルを作成
- `.ymmpx` を展開して `.ymmp` を復元
- グローバル除外と、プロジェクト単位のローカル除外を分離して管理
- プロジェクト内で参照されているが見つからない素材も除外候補として扱える
- `YmmpxLibPlugin` の導入案内
- `.ymmpx` の関連付けと展開先の制御

## インストール

1. GitHub Releases から `YMMResourcePackager.ymme` をダウンロードします。
2. YMM4 で `.ymme` を開いてインストールします。
3. 初回起動時に `YmmpxLibPlugin` の案内が出た場合は、画面の指示に従って導入します。

## 使い方

### パッケージ化

1. YMM4 で `.ymmp` プロジェクトを開きます。
2. プラグイン画面でパッケージ化を実行します。
3. 必要に応じて、出力先・除外設定・同梱設定を調整します。
4. 除外設定は、設定画面からグローバル除外とローカル除外を別々に管理できます。

### 展開

1. `.ymmpx` ファイルを開くとアンパッカーが起動します。
2. 展開先は `.ymmpx` と同じフォルダー、または指定したフォルダーを使えます。
3. 展開後は関連付けを復元し、`.ymmp` を開ける状態に戻します。

## 除外設定について

- グローバル除外は、複数プロジェクトで共通に使う設定です。
- ローカル除外は、特定の `.ymmp` / `.ymmpx` にだけ紐づく設定です。
- フォルダー単位の除外と、ファイル単体の除外を指定できます。
- 展開時の同梱除外は、同梱時のみ有効なローカル除外として扱われます。

## 依存関係

- `YmmpxLib.dll` はリポジトリや release パッケージには同梱していません。
- 実行時は `YmmpxLibPlugin` が必要です。
- 旧 `YmmpxLib` フォルダーが残っている場合は、削除案内が表示されます。
